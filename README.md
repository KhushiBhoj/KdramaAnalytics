# KdramaAnalytics 🎬

### Applying Data Analytics to Korean Drama Data

**KdramaAnalytics** is a data analytics project where I apply exploratory data analysis techniques to Korean drama datasets to uncover trends, patterns, and insights across popular K-dramas. This project blends entertainment with analytics, turning viewing data into meaningful insights.

## 📊 Project Overview

With the global rise of the *Hallyu (Korean Wave)*, K-dramas have gained massive popularity worldwide. Despite this, structured data on K-dramas is relatively limited. Using a Kaggle dataset of the **Top 100 Korean Dramas**, this project explores key features that influence popularity and viewer preferences.

---

## 🧠 Analysis Highlights

The analysis explores:

* Year of release trends
* Airing days and schedules
* Number of episodes and optimal formats
* Broadcasting networks and OTT platforms
* Episode duration patterns
* Content ratings distribution
* Ratings and statistical spread
* Genre popularity and diversity
* Tag analysis (e.g., strong female leads)
* Cast frequency and actor popularity
